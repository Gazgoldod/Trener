# Тренер — как поставить на айфон

Айфон ставит такие приложения только из интернета (по адресу https://…).
Поэтому папку `Trener` нужно один раз выложить на бесплатный хостинг. Удобнее всего — GitHub Pages: бесплатно, без рекламы, адрес не меняется.

## Шаг 1. Выложить приложение (один раз, делаем вместе с Claude)
1. Зарегистрироваться на github.com (бесплатно). Пароль и код из письма вводишь сам.
2. Claude создаёт хранилище и включает GitHub Pages. Получится адрес вида `https://ИМЯ.github.io/trener/`.

## Шаг 2. Поставить на айфон
1. Открыть адрес в **Safari** (именно Safari, не Chrome).
2. Нажать кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Выбрать «На экран "Домой"» → «Добавить».
4. Открыть «Тренер» с экрана «Домой». Дальше интернет не нужен.

## Важно
- Все записи хранятся только в телефоне. Раз в пару недель: «Ещё» → «Сохранить копию» → в «Файлы» или себе на почту.
- Если удалить иконку с экрана «Домой», записи тоже удалятся. Сначала сохрани копию.
- Таймер отдыха пищит, только когда приложение открыто на экране. Если заблокировать телефон, сигнал прозвучит, когда откроешь его снова. Время при этом считается правильно.

## Проверить на компьютере
Ярлык не нужен: запусти в этой папке команду
`py -3.12 -m http.server 8765` и открой в браузере http://localhost:8765

## Файлы
- `program.js` — программа и все упражнения (можно править, комментарии на русском)
- `app.js` — само приложение, настройки в начале файла
- `styles.css` — внешний вид
- `sw.js` — работа без интернета. После любых изменений увеличь номер версии `trener-v1` → `trener-v2`
